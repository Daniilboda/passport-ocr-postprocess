# Оригинальные данные задания

Здесь лежат материалы как в задании, без правок под решение:

- `TASK.md` — формулировка;
- `evaluate.py` — сверка ответов с разметкой;
- `data/` — исходные `train_predictions`, `train_labels`, `test_predictions`;
- `reference/` — справочник подразделений (`subdivisions.csv`).

Рабочая копия данных для экспериментов и поправленные labels — в корневом каталоге `data/`.
